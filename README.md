# Root MIDI Player 🎵🤖🤖

iRobot Root® コーディングロボットを **Web Bluetooth API** で複数台接続し、MIDI ファイルのノート情報を解析して各ロボットおよび PC 音源に最適なパート（主旋律・ドラム・ベース・シンセ・ギター伴奏等）を自動割り当てして合奏（アンサンブル）演奏する Web アプリケーションです。

🔗 **GitHub Pages 公開 URL**: [https://naominix.github.io/RootMIDIPlayer/](https://naominix.github.io/RootMIDIPlayer/)

---

## 🌟 主な機能

### 🤖 1. Root ロボットへの主旋律（メインメロディ系）優先自動割り当て
- **メロディ適性スコアリング**: MIDI ファイル内の各トラックから、平均音高・音数・単音密度を解析し、最も主旋律らしいトラック（ボーカル・リード・ピアノ・ソロ楽器等）を自動抽出。
- **Root への最適配分**: Root の歯切れの良いピエゾブザーが最大限に活きるよう、メロディ系パートを最優先で Root ロボット（#1, #2...）に割り当てます。
- **和音分散ボイス（Voice Splitting）**: 1トラックのピアノ曲でも、重なる和音を最高音（Top）・中音（Mid）・低音（Bass）ボイスに自動分割。

### 💻 2. PC ブラウザ音源の「複数パート同時演奏」＆ 高度シンセシス
- **複数パート（マルチトラック）同時担当**: PC 側は単音ではなく、**ドラム・ベース・エレキギター・シンセサイザー・和音パッド** など、単音ブザーでは表現が難しい複数トラックを同時にポリフォニックで演奏します。
- **楽器に応じたマルチティンバー合成**:
  - 🥁 **ドラム・パーカッション (Ch 10)**: キック（ピッチ下降サイン波）、スネア（ノイズ＋トーンバースト）、ハイハット（高域ハイパスノイズ）を合成発音。
  - 🎸 **低音ベース**: ローパスフィルター（350Hz）を通した太い三角波ベース。
  - 🎸 **エレキギター / バッキング**: のこぎり波 ＋ プランジ/ディケイフィルター。
  - 🎹 **シンセパッド / ストリングス**: 滑らかなアタックの広がりあるパッド音。
- **パート選択・カスタムチェック**:
  - `⚡ 自動 (Root以外の全伴奏・リズム・コード隊を担当)`
  - `全トラック (Full Mix)`
  - `カスタム選択 (トラックごとの個別ON/OFFチェックボックス)`
- **マスターコンプレッサー**: 多数のトラックと和音が重なっても音割れしない `DynamicsCompressorNode` を内蔵。

### 🤖 3. 複数台 Root のマルチ接続 & スロット色分け
- **複数台の同時接続**: 「**Rootを追加接続**」ボタンから 2 台、3 台、4 台... と複数の Root ロボットを個別にペアリング可能。
- **スロット色分け & LED連動**:
  - #1: エメラルド (`#10b981`)
  - #2: シアン (`#06b6d4`)
  - #3: バイオレット (`#a855f7`)
  - #4: アンバー (`#f59e0b`)
  - #5: ローズ (`#f43f5e`)
  - 演奏中は各 Root のトップリング LED がそれぞれのパートの音階に合わせてスロットカラーで発光します。

### 🎹 4. マルチパート ピアノロール可視化
- Root（各スロットカラー）と PC 側（ドラム・ベース・ギター・シンセ等）の全パートが色分けされたマルチレイヤー表示。
- クリックした位置へのシーク再生に対応。

## 🛠 プロトコル仕様 (iRobot Root BLE Protocol)

本アプリケーションは公式の Root ロボット BLE プロトコルに準拠しています。

- **Root Identifier Service UUID**: `48c5d828-ac2a-442d-97a3-0c9822b04979`
- **UART Service UUID**: `6e400001-b5a3-f393-e0a9-e50e24dcca9e`
- **TX Characteristic (Host → Robot)**: `6e400002-b5a3-f393-e0a9-e50e24dcca9e`
- **RX Characteristic (Robot → Host)**: `6e400003-b5a3-f393-e0a9-e50e24dcca9e`

### 送信パケットフォーマット (20 Bytes)

| バイト位置 | フィールド | 説明 |
| :--- | :--- | :--- |
| `0` | **Device ID** | `0x05` (Sound) / `0x03` (Lights) |
| `1` | **Command ID** | `0x00` (Play Note) / `0x01` (Stop Sound) / `0x02` (Set Lights) |
| `2` | **Sequence Number** | 連番 (`0`〜`255`) |
| `3..6` | **Frequency (Hz)** | 32-bit Big Endian 符号なし整数 (Play Note 時) |
| `7..8` | **Duration (ms)** | 16-bit Big Endian 符号なし整数 (Play Note 時) |
| `9..18` | **Padding** | `0x00` |
| `19` | **CRC-8 Checksum** | 0〜18バイト目の CRC-8 チェックサム |

## 🚀 動作環境

Web Bluetooth API をサポートするブラウザ（**Google Chrome / Microsoft Edge / Opera** など）で、**HTTPS** または **http://localhost** 経由でアクセスしてください。

ローカルで実行する場合:
```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。
